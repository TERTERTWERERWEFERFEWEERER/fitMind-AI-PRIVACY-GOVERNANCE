# FitMind AI – Privacy, Cybersecurity & AI Governance Assessment

## Project Overview

FitMind AI is a fictional AI-powered fitness and nutrition application designed to provide personalised workout and nutrition recommendations.

This self-directed portfolio project demonstrates how data privacy, cybersecurity and AI governance principles can be applied practically to an AI-powered application.

## Project Objectives

- Identify and document personal data processed by the application
- Map how personal data moves through the application
- Identify and assess privacy risks
- Define data retention and deletion practices
- Develop privacy and cybersecurity controls
- Assess AI governance and responsible AI considerations

## Key Areas Covered

### 1. Data Inventory
Created an inventory of personal and authentication data processed by FitMind AI, including:
- Full Name
- Email Address
- Password (Hashed)
- Age
- Height
- Weight

### 2. Data Flow Mapping
Designed a data flow showing movement of information between:
- User
- FitMind AI Application
- Application Server
- Database
- AI Service

### 3. Privacy Risk Assessment
Conducted a privacy risk assessment using an Impact × Likelihood methodology.

Key risks assessed include:
- Unauthorised access to personal data
- Excessive data sharing with an AI service
- Excessive data retention
- Inaccurate or inappropriate AI-generated recommendations

### 4. Data Retention & Deletion
Created a retention schedule defining:
- Purpose of retention
- Retention period
- Deletion trigger
- Deletion method
- Reason for retention

### 5. Privacy Controls
Developed controls covering:
- Access control
- Authentication
- Encryption
- Data minimisation
- Purpose limitation
- Retention and deletion

### 6. AI Governance
Assessed:
- AI data use
- Data minimisation
- Transparency
- Human oversight
- AI accuracy
- AI safety
- Accountability
- Monitoring



## Project Deliverables

- Business Overview
- Data Inventory
- Data Flow Diagram
- Privacy Risk Register
- Data Retention Schedule
- Privacy Controls
- AI Governance Assessment

- Final Privacy & Governance Assessment

## Disclaimer

This is a fictional portfolio project created for educational and professional demonstration purposes. It does not contain real customer or user personal data.
